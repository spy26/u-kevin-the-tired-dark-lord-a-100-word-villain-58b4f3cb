A 100-word monologue for a fantasy villain who is secretly just very tired: a dark lord who conquered the kingdom with paperwork and now taxes moonlight by the beam — losing his seal, his train of thought, and finally his will to gloat, one deflection at a time.

## Run it

```sh
python3 main.py
```

The program writes the monologue to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). It is deterministic — the same text on every run — and exits 1 if the text ever falls outside the gate (1–600 characters, about 100 words).
